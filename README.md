I build software with attention to what holds it together: clear architecture, deliberate data boundaries, and access controls. These repositories connect application engineering with AI integration and geospatial systems.

## Selected work

### 01 / Advisora

A consulting CRM portfolio project, built around the separation of workspaces, staff, and customers.

- Organization-scoped data and role-based access for internal teams.
- Separate customer portal authentication, controlled document access, and audit trails.
- Case summaries with mock and optional external AI providers.

React · TypeScript · Express · Prisma · PostgreSQL<br />
[Explore the repository ↗](https://github.com/Ductri2006/Consulting-crm-system)

### 02 / CalTrack

Food-photo analysis and meal tracking across a Flutter client and an ASP.NET Core API.

- Gemini requests stay behind the backend boundary.
- Server-backed meal diaries and seven-day statistics.
- Shared project, presented through my fork of [trangkhanh-ai/Calories-Tracking-App](https://github.com/trangkhanh-ai/Calories-Tracking-App).

Flutter · Dart · ASP.NET Core · PostgreSQL · Gemini<br />
[Explore the fork ↗](https://github.com/Ductri2006/Calories-Tracking-App) · [Open the demo ↗](https://calories-tracking-app-ten.vercel.app/)

### 03 / FloodAI

An architecture foundation for flood-aware motorcycle navigation in Vietnam.

- Web shell, typed API boundaries, and geospatial database migrations.
- Separate interfaces for data ingestion, forecasting, and evaluation.
- Development skeleton: prediction and routing logic are not implemented yet.

Next.js · TypeScript · FastAPI · PostgreSQL / PostGIS<br />
[Explore the foundation ↗](https://github.com/Ductri2006/FLOOD_AI_Hackathon)

## Engineering intent

- **Define the boundaries.** Make ownership, contracts, and access explicit.
- **Account for failure.** Treat validation and error paths as part of the design.
- **Keep the work reviewable.** Leave clear code, tests, and documentation.
- **Describe it honestly.** Distinguish implemented behavior from future plans.
