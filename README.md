Software engineering · Applied AI

- Separate portal authentication, document access controls, and audit trails.
- Case summaries through a mock provider or an optional external AI service.

React · TypeScript · Express · Prisma · PostgreSQL

[Repository](https://github.com/Ductri2006/Consulting-crm-system) · [Architecture](https://github.com/Ductri2006/Consulting-crm-system/blob/main/docs/architecture.md)

### CalTrack

A Flutter calorie tracker backed by an ASP.NET Core API. Shared codebase; [upstream project](https://github.com/trangkhanh-ai/Calories-Tracking-App).

- Food-photo analysis through server-side Gemini requests.
- Server-backed meal diaries and seven-day statistics.

Flutter · Dart · ASP.NET Core · PostgreSQL · Gemini

[My fork](https://github.com/Ductri2006/Calories-Tracking-App) · [Demo](https://calories-tracking-app-ten.vercel.app/)

## Working principles

- Check access at the API boundary, not just in the interface.
- Keep provider credentials and AI requests on the server.
- Document what works, what is mocked, and what remains unfinished.
